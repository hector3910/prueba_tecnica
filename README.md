# Prueba técnica

En este repositorio se encuentra el desarrollo de la prueba técnica. Los scripts "caso1.py" y "caso2.py" corresponden a la resolución del caso 1 y caso 2 respectivamente, mientras que el documento solicitado correspondiente al diccionario de variables del caso 2 se encuentra en el archivo "Diccionario_caso_2.xlsx". Además, como documentos de apoyo, en la carpeta notebooks se encuentra los notebooks que se desarrollaron para la posterior creación de los scripts "caso1.py" y "caso2.py".
